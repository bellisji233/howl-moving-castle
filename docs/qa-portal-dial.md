# 同步圆盘与沉浸避让 QA

2026-11-05，实时页面 http://127.0.0.1:5186/，Chrome / ANGLE Metal / Apple M5 Pro，DPR1。

## 实现

- `Portal.ts` 的横向目的地条替换为144px四色黄铜圆盘；刻度、双环与双头指针取自用户门锁参考；四个带文字象限直接选景，中央回工坊，下方名称可聚焦实体门锁。
- `DoorDial.ts` 统一实体门和SVG的扇区/角度定义；`Scene.ts` 将实体当前指针角度随原环境状态发布给UI。UI取反坐标直接绘制，无第二个动画时钟、CSS延时或额外渲染循环。
- `styles.css` 为圆盘、操作栏和展开入口保留独立区域；手机操作栏放到圆盘上方，短横屏使用旁侧双行，处理底部safe-area。
- 三维模型/材质/灯光/换景、行走、拆解、导览结构保持原路径；新增内容为小型SVG和原生按钮，没有新增依赖或网络资产。
