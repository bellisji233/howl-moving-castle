# 城堡主舞台与沉浸模式

2026-11-03。用户新反馈：核心过小、周边控件太多，希望主体放大、操作简化、拆解动效更有表现力，可加入沉浸模式。分类 structural rebuild，替代刚修正的默认三栏，不保留两条常驻侧栏。

## 体验模型与注意顺序

承诺：先遇见一座能走动、能亲手拆开的城堡，需要研究时才打开工具。
默认旅程为大幅城堡 → 开始行走/一键拆开/透视 → 点选部件 → 按需打开结构工作台 → 返回完整城堡。主舞台占主要空间，文字不再主导。沉浸状态扩大至整页、隐藏图录标题和说明，保留明确退出与直接操作。

参考用户的拆解飞行器示例：借用大主体、中心式拆解和一条运行控制；不复用其仪表盘密度与红色工业界面。结合既定纸色工坊、旧金属、暖窗，保持城堡特有的温暖与笨重感。用户三张城堡参考提供材质和形体依据。

## 结构与媒介

继续真实Three.js几何、统一步态求解，不改为平面动效。
- main为主舞台，底部一条工具栏（行走、一键拆开、透视、结构工具、沉浸）。镜头预设为轻量的第二行。
- 原左右常驻栏合为一个按需打开的工作台：速度/步态、部件说明、拆解程度/隔离/复原按顺序流式排布，内部可滚动。
- 桌面工作台打开时为真实Grid列分配空间；手机工作台在模型下占独立行，允许页面滚动，不能盖住主体。
- 沉浸模式隐藏图录装饰和镜头列表，舞台延伸，工具栏保留退出、行走、拆开和透视。Escape退出；任何状态都能找回。
- 默认模型高度目标约可用舞台的78–86%，主镜头和五个方位按实际容器比例适配；拆解时扩大包围范围，留出顶部与脚边界。

## 动效与空间计划

| 状态转换 | 起→中→终 | 双向、中断、减少动态效果 |
|---|---|---|
| 一键拆开 | 当前结构→脸先前移、建筑/烟囱分层展开、管线与腿组外移→完整分离 | 1400ms平滑加减速，各结构progress为全局amount纯函数；再按反向合拢；任意输入接管，直接滑块中断；reduced-motion直接到位 |
| 镜头配合 | 当前framing→随拆解包围缓慢让出空间→保持全体在视野 | 不绕行炫技、不自动旋转；任意拖动停止镜头过渡 |
| 工作台 | 主舞台→Grid列展开→研究布局 | 不添加飞入；保持当前选择/运动，关闭返回大舞台 |
| 沉浸 | 图录→扩大主舞台、保留操作条→自由探索 | 不强制全屏、不自动行走；退出回同一运动相位与选择 |

绝对位置+保存的姿态四元数派生拆解，不增量累积。材质贴图随网格局部运动。帧循环只插值标量、更新变换，不重建几何；保持原性能预算。保留键盘、44px目标、名称、静态减少动态设置、加载失败提示。无新音频或外部资产。
