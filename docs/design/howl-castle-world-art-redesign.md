# 魔法门景观与拨盘重设计

2026-11-03。用户明确否定第一版环境与拨盘品质，本次为 redesign；第一版作为功能原型，不作视觉验收通过。

## 体验模型与诊断

承诺：转动一件有重量的黄铜门锁，看城堡置身四个有生活痕迹的空间。关注顺序为城堡→近地植被/石岸→中景建筑/小屋→远山/天空；拨盘打开时焦点转到铜圈、搪瓷扇区与铸造指针。城堡是最大主体，景观提供真实遮挡、视差、尺度参照，不抢去控制空间。

第一版问题证据见 artifacts/door/before-landscapes.jpg：草地缺乏近景密度；树是重复球冠；建筑孤立排布且重复同一墙面；码头像悬空棋盘；夜景只有一座小方盒。拨盘是四块纯色CSS按钮，轮廓和材质缺少机械层次。只加噪点不够，须更换造景组织与拨盘构造。

## 参考分析与统一方向

1. 用户四色门结构图：借鉴黄铜阶梯边圈、外围齿轮、铜管、铆钉与矛形指针；控件保持真实文字和键盘按钮，不把图片当点击区。
2. 用户四景插画：借鉴花甸成片的深浅植被、港湾连续岸线与屋顶群、王都街巷密度、夜景暖窗小屋和大面积冷蓝天；不用第一版稀疏环形房屋阵列。
3. 用户城堡外观/细节图：保持木、氧化铜、烟熏铁和暖灰石材同一色域；场景细节尺度低于主角，不把相同城堡贴图放大贴到远楼。
4. 当前浏览器与四景接触表：以真实围绕视角为反例，修复正侧背都暴露的空旷与重复。本轮参考以用户提供的三套图和项目实拍为主，无新增电影素材。

方向：手工模型式的绘画景深。近景草花/石面、中景连续而不规则的屋顶、远处蓝灰山形与渐变云天。材料有轻微色差与使用痕迹；避免饱和塑料及巨大均匀纹理。

## 媒介、结构与三维生产链

继续用Three.js真实几何和相机；新地形有连续起伏、平坦但无色块边界的接地走廊。草花与叶片实例化，树干分叉且树冠由叶簇组成。港口由宽岸、护岸、泊船、沿岸连续建筑与对岸天际线构成。王都是不规则连续街区与钟楼。小屋采用坡地基础、斜屋顶、门窗/山墙/烟囱/庭院实物细节。

景观专用本地Canvas材质负责石板、灰泥、窗格和屋瓦的中频细节，几何负责屋脊、出檐、阳台、船体与地形轮廓。天空穹顶shader提供高度渐变、云层与远处光色；不使用整幅平面背景替代空间。共享纹理、材质合并、花草实例化；缓存四景，未选中隐藏。

拨盘UI用可访问原生按钮配合原创SVG刻度/齿轮/铜圈/搪瓷纹理；3D实物增加分层铜圈、螺钉、内凹扇区、立体指针、传动齿轮和锁轴。UI与门上指针共用同一目的地，针从当前角度走最短路径，快速连选不中断状态一致性。

## 运动与状态

保持既有1.6秒开门/雾幕/落景/关门流程，拨盘先锁定颜色再开门。正反向同样规则；更改目标以当前可见状态衔接。UI指针约550ms，外围齿轮随方向反向小幅联动；减少动态直接到位。保留步态/相位/拆解/导览/沉浸。手机拨盘不超屏，单个扇区目标大于44px，Escape关闭并返回入口。
