# 材质与 Chrome 适配修订

2026-11-03。用户明确指出材质与动画有差距，并提供 Chrome 截图：长部件说明与拆解控制相撞，标题与行走控制相撞。

## 体验和方向

材质为 skin；布局为 redesign，保留同一三维观察/拆解交互。主体仍是城堡，阅读和控制各居其位。先读标题与部件名称，再操作对应控制；长说明应在所属栏内滚动，不能挤入其他区域。

参考：用户图1的铁板斑驳、烟熏与暖炉光；图2的板块与接缝；图3的深色烟囱口、金属关节与彩窗。官方作品页作为动画画面入口补充核对。借用低饱和铁灰、赭褐、局部褪漆及手绘色块的层次，不下载电影图作贴图。不采用高亮新黄铜或均匀噪点冒充旧材质。

## 生产方法

- Three.js MeshStandardMaterial 保留真实几何、光照和拆解。确定性生成较大尺度色斑、锈蚀、烟熏、粗糙度和细微凹凸；木纹/墙灰/金属分别生成。贴图共用，不每帧创建。按部件局部坐标投影，避免原有不一致 UV 拉伸；投影只改静态几何属性。
- 模型纹理在暖主光/冷填光下保留中间调；降低均匀环境光，提升缝隙和底部的体积感。保持浅工作室背景，不添加与观察无关的场景。
- 桌面 main 为三列 Grid：左栏（标题→步态），中间独立 WebGL 画布与镜头条，右栏（说明→拆解）。侧栏采用文档流，文字高度真实参与排布；窄高条件允许本栏滚动。中间画布以容器尺寸计算相机。
- 手机为单列：标题、行走工具、中间画布、按需展开的工具或说明、镜头条。展开区占据布局空间，不能盖住模型或互相叠放。
- 主要输入至少44px，保留标签、焦点、键盘和减少动态效果。无新增自动动画。每个面板开合均可反向，Escape返回。
- 性能预算沿用<250k三角面、约250绘制调用；贴图共享，最大512px，保持按需渲染。不能以构建通过代替浏览器检查。
