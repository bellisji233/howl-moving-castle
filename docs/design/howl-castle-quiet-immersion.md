# 安静沉浸与魔法换景

2026-11-03，按用户截图反馈继续 redesign。参考：用户标出的沉浸底部实色条、四色机械门与四景插画、当前全屏四景实拍。既有问题是底部操作仍占独立Grid行，造成整幅纸色横条；雾幕换景没有体现门的因果关系。

## 体验与架构

进入沉浸→画布占满窗口→默认仅留左下魔法门、右下展开操作；展开后工具浮在画面上，主动收起后恢复安静。工具用深色半透明薄层与有限模糊保证可读，不铺实色底带。导览/播放/拆解保留原状态，收起不暂停或接管；Escape退出沉浸。手机使用同一模式，操作展开在底部入口上方，不挤压画布。开启或收起时焦点必须有明确去处，隐藏控件inert。

魔法换景仍是实时Three.js，用两个渲染目标与屏幕空间shader合成：同一当前城堡/相机分别在旧、新环境渲染，保证行走姿态一致。以真实门锁投影为发源点，环形折射波逐渐揭开新环境，前缘有细金线、目的地色光和稀疏星屑。控件与文字不参与扭曲。两张实时画面避免冻结城堡；快速改选保存当前合成帧作为下一次起点，最终仍回到实时图像。渲染目标限制尺寸，转场结束释放活动标记/回普通单次渲染，减少动态效果立即切换。

## 动作分镜

总长2.6秒：0–.18门盘转动、门缝聚光（不整屏闪白）；.18–.84空间环由门锁扩大、旧景在环外、新景在环内，边界有轻微折射和星屑；.84–1光环散去、门合拢、回到普通渲染。保持天空/地形/城堡一体空间连续，切换不强迫镜头穿门。正反选景同规则。用户旋转仍可接管导览但不破坏转场。减少动态不执行光环、星屑、开门或位移动画。

## 验收

- AC-Q1：桌面与390/375px进入沉浸，canvas四边贴满窗口；默认无底部纸色带，只有两个小入口；实际截图+DOM矩形。
- AC-Q2：展开→收起→再展开→退出，播放/导览/拆解保留；按钮>=44px，隐藏控件不在焦点顺序，键盘可返回。
- AC-Q3：至少绿→蓝与夜→昼实际转场有前中后连续采样，光环从门位置展开、不全屏闪白、不出现背景硬切；审美由用户判断。
- AC-Q4：快速改选最终一致，减少动态即到位，结束后单次渲染，无残留雾幕/光效；实际状态记录。
- AC-Q5：构建/9项测试通过；实测转场与持续播放帧间隔；只报告本机覆盖，不声称真机/低端性能。
