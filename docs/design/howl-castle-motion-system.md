# P2 / P3 运动与可逆交互方案

本次继续在已交付的 P1 之后推进完整目标。P1 五视图已经内部对照和修正圆顶层次，用户审美项仍保留未通过。运动层与部件内容分离，后续修正造型不必重做步态或拆解逻辑。

## 状态与坐标

`cycles` 为累计步态周期，是唯一运动时钟；默认暂停。固定步幅 1.35 设计单位、基准频率 0.52 周期/秒、摆动高度 0.45，均为设计假设。速度按钮/滑块改变时钟推进率，不重置周期，不显示未经验证的米/秒或扭矩。

`derivePose(cycles)` 纯函数输出主体位姿、四足世界坐标、膝关节、接地状态、关节角度与次级摇摆。输入相同则姿态相同，无足端缓存，任意跳帧均可重算。世界 Z 前进量等于步幅乘累计周期；相机和灯光跟随机身，地面的落足标记保留世界坐标。

四足相位偏移为 0、0.5、0.75、0.25，支撑比例 0.76。支撑期足端位置由整数周期直接确定，保持世界坐标不变；摆动期以 smoothstep 插值到下一落点，sin² 抬脚曲线保证起落速度连续。双骨 IK 保持两段长度，对不可达目标作明确夹取并报告，不伪造接地。

## 几何层级与生产顺序

1. 保留 14 个稳定部件根节点；静态细节仍按材质合并。
2. 四个腿组改为髋/膝/踝关节、上段、下段和足爪的独立动态节点，每段内部合并细节。实际关节坐标驱动节点，不逐帧重建网格。
3. 非腿部件挂到主体节点；主体起伏/滚转由周期确定。房屋和烟囱围绕各自连接点微量滞后摇摆，减少动态效果时关闭这些装饰动作。
4. 拆解只写部件根节点的 `original + offset * amount`，不修改运动节点。每帧从原始状态绝对求值，避免累积误差。
5. 透视仅改变外壳材质，内部传动/炉心保持实体；退出恢复原始材质。隔离保留所选部件，清除选择时退出隔离。
6. 镜头、选择、运动、拆解状态由同一控制器通知 UI。实时面板标为“设计步态”，接地和角度为求解值。

## 转换与中断

| 操作 | 起点、中间、终点 | 双向与中断规则 |
| --- | --- | --- |
| 开始/暂停 | 暂停姿态 → 累积周期推进 → 在当前周期停住 | 不归零，无重置步态；暂停时间不累计 |
| 速度调整 | 当前周期 → 新推进率 | 0.25× 到 1.5×；不修改已经确定的接地点 |
| 机身/附件动作 | 主体小幅起伏和滚转，附件相位滞后 | 均为周期函数；暂停/跳帧时完全一致 |
| 拆解 | 0 → 连续分层偏移 → 100% | 可立即反向，播放和暂停下都从原始变换求值 |
| X-ray | 实体 → 外壳透明，保留内部结构 | 不改变几何/相位，退出恢复材质 |
| 隔离 | 整体 → 当前部件 | 所选部件变化时同步；退出或清除选择恢复整体 |
| 自动导览 | 完整 → 鸟足 → 脸部 → 拆解 → 内部 → 完整 | 明确按钮启用；用户输入 ≤100ms 接管，保留当前视图；35 秒闲置才恢复；减少动态效果禁止自动巡游 |

## 界面、设备与回退

桌面以底部运动/拆解工具和右侧步态读数组成辅助层，中央城堡保持主焦点。手机把扩展功能放入可开合的操作面板，常用播放按钮保留在外；按钮最小 44px。使用原生按钮和 range，提供标签、焦点与键盘操作。面板不将动画读数放在频繁播报的 aria-live 区域。

浏览器隐藏或恢复时重设墙钟采样基线，防止后台停顿造成突然跃迁；纯姿态函数不依赖该运行策略。减少动态效果仍允许用户主动开始四足运动，但关闭自动镜头和附件装饰摇摆。
