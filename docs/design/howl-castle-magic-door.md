# 魔法门与四个环境

2026-11-03，用户明确要求加入四色魔法门并通过门切换周围环境，提供拨盘结构与四目的地插画。按 redesign 扩展既有主舞台，保留城堡为视觉核心。

## 体验、参考与范围

主旅程：打开魔法门控件 → 选择颜色/目的地 → 黄铜拨盘转动、木门开启 → 短雾幕跨越 → 新环境显现、门关闭 → 继续绕行/步行/拆解。四个目的地以用户最新图为准：绿色花田、蓝色港口、红色王都、黑色星夜小屋。它们是本项目的艺术化景观，不声称官方工程或地理还原。

参考提取：图1的四色扇区、铜圈、指针和外露传动表达“选择驱动一个实体机构”；图2的草丘与小花、低饱和港湾、暖色城市、蓝色星夜与暖窗小屋提供四套空间/材质/光照方向。沿用既有图1/图3的烟熏金属与木屋质感。借用原则，原创几何，不把整张插画贴成背景。

非目标：角色、战斗/毁坏系统、可进入的完整室内、真实传送物理、镜头强制穿门、电影音乐。保留工坊环境供结构观察与返回。

## 三维生产链

- 木门安装在右上木屋外侧阳台上，真实门框、门板、铰链、四色圆盘和金属指针，随HOUSE_B运动/拆解；点击拨盘可打开同一可访问控件。
- 地形以低密度顶点着色网格形成宽缓草丘，中心步行走廊平坦；草花用实例化低面几何，花田不侵入足端范围。
- 港口有实体步道、海面网格、波纹材质、帆船/桅杆、码头与远处建筑；城堡足下保留陆地。
- 王都有低饱和暖墙、屋顶、远塔与烟色暮空，保留中间的石路及城堡轮廓。
- 星夜有深蓝天空、星点、真实坡地和暖窗小屋，冷月光与暖窗形成焦点；避免仅换背景色。
- 地景在世界空间中保持稳定，远处片区按步行位置循环接续；雾距之外才换片区。脚锁定和地面仍使用原步态世界坐标。
- 采用Three.js实时几何，贴图仍本地生成；无新外部资产和依赖。景观优先实例化、合并；统计每个环境三角面/调用，性能降级减少草花/星点和阴影，不隐藏城堡。

## 运动、状态与可访问性

默认是工坊，左下“魔法门”入口打开紧凑四色拨盘面板；手机面板有自己的最大高度与滚动，44px目标、文字目的地、aria-pressed、键盘可操作，不能只靠颜色。Escape关闭并返回入口。沉浸模式仍能打开。

切换约1.6秒：0–.35拨盘转动、木门打开；.25–.6雾幕收近遮掩景物更换；.5切换景观；.6–1雾散、门合拢。灯光和天空平滑过渡，镜头不强制跳转。反向任意目的地同一流程。快速再选时以前一可见景观/当前颜色为起点，最后一次选择生效，无重复对象堆积。

减少动态效果直接切换，不转盘/开门/闪光；保留主动控制。切换环境保留步态相位、播放/速度、拆解/隔离、选择与导览启用状态。切换不当作接管导览；拖动场景仍即时接管。
