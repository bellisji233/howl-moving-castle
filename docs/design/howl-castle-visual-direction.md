# 城堡工坊 · P0 视觉与空间方案

## 体验模型

承诺：靠近一座有生活痕迹的步行城堡，辨认它怎样拼在一起。情绪是好奇、温暖与沉重机械的反差。P1 先呈现完整、静止、可绕行的三维实体；P2 起加入行走，P3 加入解构。

注意顺序为中央城堡 → 左上展品标题 → 底部观察工具 → 右侧部件说明。场景占主体，界面采用博物馆工坊图录：纸白、细线、小型编号、衬线标题、克制的深赭色选中态。没有仪表盘卡片网格。

P1 状态：初始化、完整英雄视角、五个预设、自由绕行/缩放、部件选择、信息面板开合、加载失败/WebGL 不可用。P1 不展示未实现的行走、拆解开关。

## 参考分析

1. 用户图 2：正面三个不等高金属圆顶、眼状炮口、下方嘴形入口是识别核心。取其层叠与脸部组织，不复制互不一致的尺寸。
2. 用户图 1：半嵌的房屋、暴露侧传动、炉火、歪斜管线使建筑与机器融合。取其暖窗与冷铁、侧面结构密度；不把剖视图当外表面的装饰贴图。
3. 用户图 3：活塞、关节盖、三趾足、烟囱节箍与彩窗提供尺度。取可建模细节与局部节奏，腿长比例服从统一模型。
4. 用户图 4：黄铜与褪色彩玻璃作为远期魔法门专题参考，首版不加入独立门机构。
5. [Matt Benson 分层动画教程](https://www.mattgyver.com/tutorials/2021/3/1/howls-moving-castle-animated)：已阅读原文；部件应独立完整，重叠关系、板缝和铆钉比随机细节重要。取结构拆分与材料节奏，采用真实几何及较缓慢运动，不复用其矢量文件或素材。

补充核对：[吉卜力官方作品页](https://www.ghibli.jp/works/howl/) 与 [Gillian Morio 项目说明](https://yuguhtrrh.artstation.com/projects/GaQJKa)。后者文字说明用于理解资产制作复杂度；本轮没有获得源模型，不将其算作可复用资产或已完成多视图视觉研究。

## 统一空间结构

坐标：Y 向上，+Z 为正面，X 为左右。无现实尺寸承诺。总高约 14.5，机身宽约 6，四足展开宽约 7.5，前后约 8。四足到机身约占 24% 高度；机身与建筑约 48%；长烟囱构成余下天际线。

```text
             长短错位烟囱 / 晾衣架
        歪屋顶 + 后方房屋 + 铜绿塔
       左小圆顶   主圆顶脸   右侧房屋
       管道     双炮眼     侧齿轮
          下颌 / 舌形入口 / 船腹
       前左腿 前右腿 后左腿 后右腿
```

正面：宽圆钝机械脸、两只黑色炮眼、嘴形入口、两侧鳍板与小屋。左侧：炉房、阳台、曲管与大型节箍。右侧：齿轮、楼梯、侧塔与管线。背面：船腹壳板、承重框架、后屋、排气管与后足。顶部：屋脊、各烟囱根部、连接走道均有实体支撑。

分件 ID：CORE、FACE、HOUSE_A、HOUSE_B、HOUSE_REAR、TURRETS、CHIMNEYS、PIPES、FL_LIMB、FR_LIMB、BL_LIMB、BR_LIMB、DRIVE、FIRE。每组独立挂载，保存局部原始变换，未来拆解在外层节点实施，不修改部件内部建模坐标。

## 3D 生产链

1. 先用 lathe、分区球壳、挤出屋顶、弯管和关节连杆建立结构；壳板使用分片与接缝，不以一只完整球体替代机身。
2. 有选择地加入铆钉、窗框、瓦片、支撑梁、梯子和栏杆；重复细节按部件合并或实例化。
3. 确定性生成色差、锈斑和木纹，粗糙度为主、适中金属度；不使用镜面塑料高光。P1 材质为方向验证，保留精修状态。
4. 暖色大面主光、偏冷填光、轮廓光，地面软投影；相机以透视与真实遮挡呈现深度。
5. 三分之四英雄镜头看见正面和齿轮侧；相机目标在城堡高度中部，缩放受限，保持地面以上。五视图按模型包围盒适配。
6. P2 实施世界坐标足端锁定、双骨 IK、统一相位及小幅次级晃动。P1 只保存静态姿态，不假报运动。
7. 交付 Vite 静态构建，代码生成几何；未来可按 ID 替换 GLB，复杂资产不内联。
8. 目标 < 250k 三角面、< 250 绘制调用（重复几何合并），首屏压缩资源目标 < 2MB；像素比桌面上限 1.5、手机 1.25。低性能先减阴影与像素比，保留造型。

## 运动和状态计划

| 转换 | 起点 → 中间 → 终点 | 时长/打断/反向 |
| --- | --- | --- |
| 初次加载 | 纸色背景与文字状态 → 几何/材质编译 → 完整场景 | 首帧完整，不缩放飞入；失败显示原因与重试 |
| 镜头预设 | 当前相机 → 球面角与距离平滑插值 → 目标视角 | 650ms ease-in-out；拖动或新预设立即接管；反向从当前值开始 |
| 部件选择 | 默认材质 → 轻量暖色高亮 → 显示名称与说明 | 立即反馈；不移走其他部件；清除恢复原材质 |
| 面板 | 关闭 → 侧向短距离出现 → 打开 | 180ms transform/opacity；Escape 关闭并恢复焦点；手机为底部面板 |
| 未来拆解 | 完整 → 连续分层偏移 → 分离 | 直接跟随滑块，往返无累计误差；播放姿态和拆解偏移分层 |
| 未来巡游 | 整体 → 鸟足 → 脸 → 爆炸 → 内部 → 整体 | 输入后 ≤100ms 退出；35 秒无输入才恢复；reduced-motion 禁止自动巡游 |

P1 没有自动旋转。减少动态效果时镜头预设立即到位、面板无过渡。键盘可访问镜头和部件列表；触控使用单指旋转、双指缩放。

## 架构与响应式

`howl-castle-app/src/world/` 负责场景与几何，`assets/` 负责分件元数据，`interaction/` 负责选择与相机，`ui/` 负责状态和说明。选择从三维网格上溯部件 ID；界面清单也能触发同一选择逻辑。

桌面 1600×900：全幅场景、左上标题、右侧可收起说明、底部镜头条。1280×800 缩小说明宽度、按可见场景宽度重构相机。390×844/375px：简化标题，底部镜头工具条，按需展开部件面板，不能用覆盖主要城堡的固定侧栏。

加载状态、可见焦点、44px 点击目标、对比度和 WebGL 错误说明属于 P1 基础。P2/P3 未实现控制不出现在首轮界面。
