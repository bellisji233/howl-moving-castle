# 哈尔的移动城堡 · 奇想建筑工坊

真实 Three.js 网格、四足步态和可逆拆解。默认以大幅城堡为主，常用操作放在底部，详细读数与部件说明收进按需打开的结构工作台。

## 运行

本次环境为 Node 22.15；建议 Node 22.12 或更新版本。

```sh
npm ci
npm run dev -- --port 5186
```

打开终端显示的地址，本项目当前使用 `http://127.0.0.1:5186/`。已启动服务时直接刷新。构建和检查：

```sh
npm test
npm run build
npm run preview -- --port 4186
```

`dist/` 可由静态 HTTP 服务运行，无后端；不要用 file 协议直接双击。字体在本地，纹理由代码确定性生成，不请求远程图片。

## 体验

- 拖动绕行、滚轮/加减按钮缩放。观察视角菜单提供三分之四、正面、左侧、背面、顶部与重置。
- 开始/暂停行走；在结构工作台修改速度、拖动周期、查看实际接地与关节读数。
- “拆开城堡/合拢城堡”执行约1.4秒的分层动画；工作台滑块可直接指定程度。两种操作均保持步态状态。
- 透视外壳、点选/索引选件、隔离、复原可组合。内部机构标注为创意机械推演，不展示虚构实测压力/扭矩。
- 沉浸模式让画布铺满窗口，默认只留魔法门与“展开操作”两个小入口。常用工具可展开/收起，深色半透明薄层不挤占画面；收起时导览、播放和拆解继续。Escape退出。
- 自动导览与沉浸模式独立，可以同时开启；切换沉浸不打断导览。拖动、普通控制或键盘探索会接管；导览仍启用时闲置35秒后继续。点击停止导览可彻底关闭。
- 左下四色黄铜圆盘一键切换花田、港口、王都、星夜，中央返回工坊；屏幕指针与实体门锁逐帧同步（数字键 1–5，点击场景里的魔法门也会转到下一处）。新环境从城堡脚下向外展开、地面像立体书一样立起，天空随后从头顶合拢；灯光、雾和反射同步过渡。换景保留步态、拆解、选择和导览；重置姿态/镜头保留所选环境。
- 减少动态效果时关闭自动导览、镜头过渡和装饰晃动；主动行走可用，一键拆解和换景直接到位。
- 桌面工作台占独立侧列；手机工作台排列在模型下面，页面可纵向滚动。

## 代码与证据

```text
src/world/             原创分件几何、材质、光照与交互
                       Lighting.ts 各目的地灯光与反射；Reveal.ts 换景展开；Pipeline.ts AO/泛光/色调映射
src/simulation/        确定性步态、世界触地锁定、双骨IK
src/tour/              导览时间线及接管逻辑
src/assets/parts.ts    14个稳定部件ID与说明
src/ui/                主舞台、工作台、索引及操作
artifacts/immersion/   当前安静沉浸、手机、光环过程与运行证据
artifacts/door-v2/     重做四景/拨盘、门锁近景、状态/矩阵回归
artifacts/stage/       早期主舞台/手机截图、拆解双向采样
artifacts/revision/    材质与三栏适配修订过程（主舞台已替代三栏）
artifacts/p1,p2,p3,p4/  各阶段历史证据，不代表当前界面
../docs/               目标、参考、资产审计、设计、验收和QA记录
```

纯状态测试覆盖世界触地、IK边界、时间连续性、相位确定性、导览顺序和接管延时。浏览器截图证明其对应状态；拆解序列与网格矩阵比较另证明双向过程和复原。

## 当前边界

本项目仍为原创程序化风格化重建。新一轮材质加强了铁/铜氧化、烟熏、木纹、墙灰和屋顶色差，尚未获得用户对电影造型及材质还原度的最终审美通过。不是官方精确模型，也不是工程动力学仿真。

已做 Chrome 与手机尺寸覆盖检查；手机真实触控和低端设备性能尚需真实设备。具体范围及未验收项见 `../docs/qa-stage.md`。当前魔法门与四景的实现、证据和限制见 `../docs/qa-magic-door.md`。视频成片未包含。在线版本与自动发布说明见[项目首页](../README.md)。

没有内嵌电影画面、音乐或第三方城堡模型。原作形象归相应权利方；字体许可证位于 `public/fonts/`，依赖锁定在 `package-lock.json`。
